# 奶蛙：快乐回收站 — 俯瞰 2.5D

可实际游玩的动作 Roguelite Demo。Phaser **4.0.0** + TypeScript + Vite + Arcade Physics，基于 [Phaser 官方 TypeScript + Vite 模板](https://github.com/phaserjs/template-vite-ts) 的工程配置开发。主角使用用户提供的黄色角色生成本地透明素材，场景与敌人仍由代码绘制；音乐与音效为本地生成素材，无在线图片、字体或音频依赖，无后端与 UI 框架。

## 原创故事与场景

**表情包岛的快乐缓存突然掉线。** 复读、阴阳弹幕和红温挤满了频道。黄色身体、绿色大眼睛的奶蛙带上一口奶香，深入百层缓存，回收被坏情绪吞掉的笑点，让蛙友重新连线。这是为本游戏创作的故事设定。

主场景是「笑声缓存岛 · 蛙友广场」：奶油黄与薄荷青的菱形地砖、绿眼奶蛙地贴、瓶装路灯、蛙眼信号塔、表情快递箱、气泡隔断、快乐补给机，以及外围的奶泡水渠。三类敌人分别为复读小怪、弹幕法师和红温保安。穿过复读中继站、阴阳弹幕塔与红温总控室，击败三位首领后进入「快乐小卖部」庆功，领取「蛙友快乐认证」。

近战使用奶盖铲，法师使用奶泡法杖，弓箭使用蛙友长弓；加成以「快乐加一」「奶香续杯」「滑走滑走」等名称呈现，卡片仍明确显示实际属性变化。菜单、加载、HUD、暂停、升级、死亡、结算、网页标题和全屏应用名称都统一使用奶蛙主题。场景、小怪、首领和职业武器继续使用本地程序化绘图；已有角色图集、BGM 与音效保留。

## 启动

GitHub Pages 试玩地址：**https://tooxtox.github.io/naiwa_game/**。

仓库的 `.github/workflows/deploy-pages.yml` 会在推送到 `main` 时自动执行 `npm ci`、类型检查和生产构建，再将 `dist/` 发布到 GitHub Pages；也支持在 Actions 页面手动运行。Pages 发布来源设为 **GitHub Actions**。生产构建使用相对资源路径，支持 `/naiwa_game/` 子路径，也保留本地 FRP 分享兼容性。

建议 Node.js 22 LTS（或 20.19+）。

```bash
npm install
npm run dev
```

打开 **http://localhost:8080/**。同一 Wi-Fi 的手机访问终端打印的 Network 地址。

```bash
npm run typecheck   # 严格 TypeScript 检查
npm run build       # 类型检查 + 生产构建，输出 dist/
npm run preview     # 预览生产构建
```

本机现有樱花 FRP 将 `https://www.u2387222.nyat.app:46760/` 映射到 `127.0.0.1:2778`。分享生产构建：

```bash
npm run build
python3 -m http.server 2778 --bind 127.0.0.1 --directory dist
```

FRP 和静态服务保持运行即可访问；更新构建后刷新网页。`dist/` 使用相对资源路径，也可部署到普通静态 HTTP 服务。

当前机器也已配置并启用用户后台服务 `lumenfall-dev` 与 `lumenfall-share`，用户登录后会自动启动。已有服务运行时无需重复执行上面的启动命令；需要重启时使用：

```bash
systemctl --user restart lumenfall-dev lumenfall-share
```

## 当前玩法

- **参考角色实装**：黄色圆润身体、绿色大眼睛、浅色肚皮与深色手脚；三向行走加左右镜像，独立攻击、冲刺与受伤表现。菜单、HUD 头像、冲刺残影都使用相同角色，脚底碰撞不随身体动画改变。
- **俯瞰 2.5D 蛙友广场**：1920 × 1280 可探索场地、奶油菱形铺装、奶蛙地贴、奶泡水渠，以及带顶面、侧面和投影的随机奶瓶路灯、气泡隔断与表情快递箱。
- **真正双轴移动**：桌面使用 WASD / 四向箭头；手机在屏幕左侧 1/3 的全高触控区按下，浮动 360° 摇杆出现在按下位置，拖动控制方向、松手隐藏并停止移动。斜向输入归一化，纵向按地面透视比例移动。
- **角色与场景按脚底 Y 排序**：站到柱子后会被遮挡，走到前面会覆盖柱子。角色阴影留在地面，脚底坐标用于碰撞。
- **最近目标自动索敌**：按住攻击，自动瞄准距离最近的存活敌人；近战仍需靠近，远程攻击受射程与掩体约束。冲刺沿移动方向，站定时沿朝向冲刺。
- **三条职业路线**：主菜单选择近战、法师或弓箭，具有独立初始属性、武器表现、专属加成和终结技，重开保留职业、重置本局成长。
- **格挡与终结技**：跳跃已移除。格挡持续 0.65 秒，前 0.18 秒为完美格挡，可免伤、震慑近处敌人、清除近处弹幕并充能；普通格挡减伤 80%。命中与击杀积累终结能量，满能量后主动释放。
- **三类敌人**：近战追击、远程三弹、精英蓄力冲锋与扇形弹幕。共享寻路网格绕过掩体，弹丸被掩体阻挡。危险圈和冲锋线显示蓄力方向。
- **音乐与音效**：菜单与三种职业各有独立循环 BGM，战斗包含挥砍、射击、命中、暴击、击杀、格挡、完美格挡、冲刺、受伤、终结、获得加成、波次开始与结算音效。右上角音符按钮可一键静音，Web Audio 解锁前会等待首次手势。
- **百关战役**：菜单 → 波次战斗 → 波末手选 / 自动成长 → 35、75、100 关首领 → 通关奖励房与领奖结算；死亡可随机重开，不会生成第 101 关。

击杀达到 4、9、14……时积累一次加成资格：**前 10 次**（击杀门槛 4～49）在战斗中只增加「波末待选」次数，不会中断当前波。清空敌人后统一进入波末结算，依次从最多三个不同加成中手选，候选包含当前职业专属加成。选完本波所有待选加成才进入下一波。**第 11 次起**（击杀门槛 54 起，每增加 5 次击杀）使用同一职业的有效候选池自动随机选择并立即生效，战斗与触控不中断，不再弹出选择界面。

**每种增益单局最多选择 5 次。** 达到上限的增益会立刻移出候选池，候选不足三张时只显示剩余数量；卡片底部显示 `LV. n → n+1 / 5`。全部增益都用满后不再发放加成，仅在首次耗尽时提示一次「快乐加成已达上限」；之后击杀门槛继续推进，HUD 静默显示「增益已满」，不会反复弹出提示。

HUD 下方显示「手选 N/10 · 波末待选 M」、「自动加成 · 已获 N」或满级状态。自动获得的加成通过从右向左滚动的弹幕显示：获得序号、名称、等级和真实数值变化；最多同时显示三条，密集获得时按加成类型排队、合并并展示最新效果与累计次数。弹幕整体不透明度降到 48%（`--barrage-opacity`），不再遮挡战场视线。弹幕不拦截触控，暂停时停止滚动，死亡或重开清理。攻击、最大生命、攻速、冲刺冷却、移速和暴击均真实修改数值；成长只在本局生效。升级、击杀与波次切换恢复少量生命。第二波起加入精英。

敌人每次生成时按当前波次从基础生命重新计算。令 `w = max(1, floor(波次))`、`n = w − 1`、`p = max(0, w − 35)^2`：

- 生命倍率：`1 + 0.16n + 0.025n^1.5 + 0.004p`。
- 伤害倍率：`1 + 0.1n + 0.00025p`。
- 最终生命和伤害为基础值乘对应倍率后四舍五入；从第 36 关起增加额外压力，不把上一波生命继续连乘。
- 速度每波增加基础值的 3.5%，最多计算 12 波增长。

## 音频

- **BGM**：`public/assets/audio/bgm-menu.mp3`、`bgm-warrior.mp3`、`bgm-mage.mp3`、`bgm-archer.mp3`，四段离线生成的无人声循环曲，44.1 kHz 立体声 MP3。菜单使用环境曲，进入战斗后切换为当前职业曲，暂停时暂停、结算后保留。
- **音效**：`scripts/make-sfx.mjs` 用振荡器、滤波噪声和包络实时合成 15 个 16-bit 单声道 WAV（挥砍、射击、命中、暴击、击杀、冲刺、格挡、完美格挡、受伤、终结、加成、波次、死亡、界面、敌方射击）。仓库内包含可直接播放的 WAV 成品，重新合成只需 `node scripts/make-sfx.mjs`。
- **播放**：`BootScene` 随角色图集一起加载音频；`AudioManager` 挂在 Phaser game 上，跨场景保留 BGM，并用 3 声部的小池播放一次性音效。浏览器要求首次手势后才允许出声，因此解锁前的曲目会先挂起，`unlocked` 事件到达后再开始播放。右上角音符按钮切换全局静音，状态在场景切换后保持。

## 移动端全屏

画布使用 **RESIZE** 铺满当前视口，`100dvh` 跟随浏览器可用高度，不固定 16:9 留黑边、不拉伸画面。相机按 540 单位的基准可见高度调整缩放，宽屏显示更多横向场地。渲染分辨率按 CSS 视口，不随 DPR 倍增；HUD 和触控避开安全区。

在支持 Fullscreen API 的浏览器上，点击开始、继续或重开时会在真实用户手势内请求隐藏浏览器导航栏，并尝试锁定横屏。右上按钮随实际全屏状态变化。网页不能强制不支持该接口的浏览器全屏：iPhone Safari 会提供「分享 → 添加到主屏幕」说明，独立启动使用全屏/独立窗口配置。`public/manifest.webmanifest` 及 Apple 全屏 meta 已配置；不包含离线缓存功能。

竖屏提供旋转提示并暂停；回到横屏后点击继续。多点触控采用独立 Pointer 捕获。左侧 1/3 是全高浮动摇杆触控区，按下时以手指落点为中心显示摇杆，拖动即可控制全向移动，松开后摇杆隐藏并归零；移动与右侧攻击、格挡、冲刺和终结互不抢触点。失焦、切换应用或暂停时清理输入，桌面仍保留 WASD / 四向箭头。

```text
src/main.ts                     引擎、RESIZE、全屏初始化
src/game/config.ts              集中数值与公共类型
src/game/theme.ts               奶蛙原创故事、场景与主题命名
src/game/scenes/                 Boot / Menu / Game 生命周期
src/game/entities/               Player / Enemy 地面物理与独立渲染
src/game/systems/
  InputManager.ts               统一双轴键盘/触控输入
  FullscreenManager.ts          全屏、横屏锁定及平台回退
  NavigationGrid.ts             障碍寻路与独立攻击视线
  CombatSystem.ts               最近目标、三职业攻击、弹幕池、格挡与终结
  MapGenerator.ts               种子蛙友广场与立体掩体
  WaveSystem.ts                 波次、全平面安全生成
  DifficultySystem.ts           波次、35 关后的压力与首领生命计算
  RewardRoom.ts                 百关通关后的奖励房、宝箱与领取状态
  UpgradeSystem.ts              数据驱动加成、前 10 次手选与后续自动成长
  Effects.ts                    粒子、残影和伤害数字池
  AudioManager.ts               BGM 循环、音效池、静音与 Web Audio 解锁
src/game/graphics/              程序化环境、角色动画与 WeaponRenderer 职业武器
src/game/ui/                    HUD、模态界面、摇杆和触控
public/assets/hero/             本地角色 PNG 与 Phaser 图集 JSON
public/assets/audio/            4 首循环 BGM（MP3）与 15 个程序化音效（WAV）
scripts/make-sfx.mjs            重新合成音效库（node scripts/make-sfx.mjs）
scripts/verify-audio.mjs        校验音频加载、播放与静音
docs/art/hero-prompts.md        生成提示词、素材来源与整理说明
```

actor 的位置代表脚底，碰撞只覆盖脚底。主角的视觉锚点为 `(0.5, 0.94)`，使用透明留白对齐脚掌；其他角色为 `(0.5, 1)`。地板静态图形烘焙为一张 RenderTexture，立体道具按深度单独绘制。敌方子弹最多 96、玩家投射物 64、粒子 100、伤害数字 12、敌人 15。

角色图集使用内置 `image_gen` 生成，原图保存为 `public/assets/hero/hero-atlas-v1.png`，头像为 `portrait.png`。`hero-atlas-v1.json` 将 16 个角色区域整理到统一的虚拟画布，不修改原 PNG 像素。需要重新整理时可手动运行 `python3 scripts/prepare-hero-atlas.py`（需要 Pillow）；正常安装、启动和构建不需要 Python 或图像生成服务。生成提示词和参考图保存在 `docs/art/`。
