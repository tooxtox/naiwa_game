# 霓渊 · LUMENFALL — 俯瞰 2.5D

可实际游玩的动作 Roguelite Demo。Phaser **4.0.0** + TypeScript + Vite + Arcade Physics，基于 [Phaser 官方 TypeScript + Vite 模板](https://github.com/phaserjs/template-vite-ts) 的工程配置开发。主角使用用户提供的黄色角色生成本地透明素材，场景与敌人仍由代码绘制；音乐与音效为本地生成素材，无在线图片、字体或音频依赖，无后端与 UI 框架。

## 启动

建议 Node.js 22 LTS（或 20.19+）。

```bash
npm install
npm run dev
```

打开 **http://localhost:8080/**。同一 Wi-Fi 的手机访问终端打印的 Network 地址。

```bash
npm run typecheck   # 严格 TypeScript 检查
npm run build       # 类型检查 + 生产构建，输出 dist/
npm run preview     # 预览生产构建
```

本机现有樱花 FRP 将 `https://www.u2387222.nyat.app:46760/` 映射到 `127.0.0.1:2778`。分享生产构建：

```bash
npm run build
python3 -m http.server 2778 --bind 127.0.0.1 --directory dist
```

FRP 和静态服务保持运行即可访问；更新构建后刷新网页。`dist/` 使用相对资源路径，也可部署到普通静态 HTTP 服务。

当前机器也已配置并启用用户后台服务 `lumenfall-dev` 与 `lumenfall-share`，用户登录后会自动启动。已有服务运行时无需重复执行上面的启动命令；需要重启时使用：

```bash
systemctl --user restart lumenfall-dev lumenfall-share
```

## 当前玩法

- **参考角色实装**：黄色圆润身体、绿色大眼睛、浅色肚皮与深色手脚；三向行走加左右镜像，独立攻击、冲刺与受伤表现。菜单、HUD 头像、冲刺残影都使用相同角色，脚底碰撞不随身体动画改变。
- **俯瞰 2.5D 庭院**：1920 × 1280 可探索场地、菱形铺装、法阵、水渠，以及带顶面、侧面和投影的随机立柱、矮墙与箱子。
- **真正双轴移动**：WASD / 四向箭头与 360° 摇杆。斜向输入归一化，纵向按地面透视比例移动。
- **角色与场景按脚底 Y 排序**：站到柱子后会被遮挡，走到前面会覆盖柱子。角色阴影留在地面，脚底坐标用于碰撞。
- **最近目标自动索敌**：按住攻击，自动瞄准距离最近的存活敌人；近战仍需靠近，远程攻击受射程与掩体约束。冲刺沿移动方向，站定时沿朝向冲刺。
- **三条职业路线**：主菜单选择近战、法师或弓箭，具有独立初始属性、武器表现、专属祝福和终结技，重开保留职业、重置本局成长。
- **格挡与终结技**：跳跃已移除。格挡持续 0.65 秒，前 0.18 秒为完美格挡，可免伤、震慑近处敌人、清除近处弹幕并充能；普通格挡减伤 80%。命中与击杀积累终结能量，满能量后主动释放。
- **三类敌人**：近战追击、远程双弹、精英蓄力冲锋与扇形弹幕。共享寻路网格绕过掩体，弹丸被掩体阻挡。危险圈和冲锋线显示蓄力方向。
- **音乐与音效**：菜单与三种职业各有独立循环 BGM，战斗包含挥砍、射击、命中、暴击、击杀、格挡、完美格挡、冲刺、受伤、终结、获得祝福、波次开始与结算音效。右上角音符按钮可一键静音，Web Audio 解锁前会等待首次手势。
- **完整循环**：菜单 → 波次战斗 → 前 10 次手选成长 → 自动成长与更强波次 → 死亡结算 → 随机重开。

击杀达到 4、9、14……时获得一次加成：**前 10 次**（累计击杀 4～49）暂停战斗，从三个不同祝福中手动选择，每次至少包含一个当前职业专属祝福。**第 11 次起**（累计击杀 54 起，每增加 5 次击杀）使用同一职业的有效候选池自动随机选择并立即生效，战斗与触控不中断，不再弹出选择界面。

**每种增益单局最多选择 5 次。** 达到上限的增益会立刻移出候选池，候选不足三张时只显示剩余数量；卡片底部显示 `LV. n → n+1 / 5`。全部增益都用满后不再发放祝福，击杀门槛照常推进并提示「祝福已达上限」，战斗强度随波次继续增长。

HUD 下方显示「手选 N/10」或「自动加成 · 已获 N」。自动获得的加成通过从右向左滚动的弹幕显示：获得序号、名称、等级和真实数值变化；最多同时显示三条，密集获得时按加成类型排队、合并并展示最新效果与累计次数。弹幕整体不透明度降到 48%（`--barrage-opacity`），不再遮挡战场视线。弹幕不拦截触控，暂停时停止滚动，死亡或重开清理。攻击、最大生命、攻速、冲刺冷却、移速和暴击均真实修改数值；成长只在本局生效。升级、击杀与波次切换恢复少量生命。第二波起加入精英。

敌人每次生成时按当前波次从基础生命重新计算，使用渐增的相加公式：`n = max(0, floor(波次) − 1)`，`生命倍率 = 1 + 0.16n + 0.025n^1.5`，最终生命为基础生命乘该倍率后四舍五入。不会把上一波生命继续连乘。伤害仍每波增加基础值的 10%，速度仍每波增加基础值的 3.5%（最多计算 12 波增长）。

## 音频

- **BGM**：`public/assets/audio/bgm-menu.mp3`、`bgm-warrior.mp3`、`bgm-mage.mp3`、`bgm-archer.mp3`，四段离线生成的无人声循环曲，44.1 kHz 立体声 MP3。菜单使用环境曲，进入战斗后切换为当前职业曲，暂停时暂停、结算后保留。
- **音效**：`scripts/make-sfx.mjs` 用振荡器、滤波噪声和包络实时合成 15 个 16-bit 单声道 WAV（挥砍、射击、命中、暴击、击杀、冲刺、格挡、完美格挡、受伤、终结、祝福、波次、死亡、界面、敌方射击）。仓库内不存放二进制音效源文件，重新合成只需 `node scripts/make-sfx.mjs`。
- **播放**：`BootScene` 随角色图集一起加载音频；`AudioManager` 挂在 Phaser game 上，跨场景保留 BGM，并用 3 条复voice 的小池播放一次性音效。浏览器要求首次手势后才允许出声，因此解锁前的曲目会先挂起，`unlocked` 事件到达后再开始播放。右上角音符按钮切换全局静音，状态在场景切换后保持。

## 移动端全屏

画布使用 **RESIZE** 铺满当前视口，`100dvh` 跟随浏览器可用高度，不固定 16:9 留黑边、不拉伸画面。相机按 540 单位的基准可见高度调整缩放，宽屏显示更多横向场地。渲染分辨率按 CSS 视口，不随 DPR 倍增；HUD 和触控避开安全区。

在支持 Fullscreen API 的浏览器上，点击开始、继续或重开时会在真实用户手势内请求隐藏浏览器导航栏，并尝试锁定横屏。右上按钮随实际全屏状态变化。网页不能强制不支持该接口的浏览器全屏：iPhone Safari 会提供「分享 → 添加到主屏幕」说明，独立启动使用全屏/独立窗口配置。`public/manifest.webmanifest` 及 Apple 全屏 meta 已配置；不包含离线缓存功能。

竖屏提供旋转提示并暂停；回到横屏后点击继续。多点触控采用独立 Pointer 捕获；移动、攻击、格挡、冲刺和终结互不抢触点，松手、失焦、切换应用时清理输入。

## 工程结构

```text
src/main.ts                     引擎、RESIZE、全屏初始化
src/game/config.ts              集中数值与公共类型
src/game/scenes/                 Boot / Menu / Game 生命周期
src/game/entities/               Player / Enemy 地面物理与独立渲染
src/game/systems/
  InputManager.ts               统一双轴键盘/触控输入
  FullscreenManager.ts          全屏、横屏锁定及平台回退
  NavigationGrid.ts             障碍寻路与独立攻击视线
  CombatSystem.ts               最近目标、三职业攻击、弹幕池、格挡与终结
  MapGenerator.ts               种子庭院与立体掩体
  WaveSystem.ts                 波次、全平面安全生成
  DifficultySystem.ts           从波次与基础生命计算敌人血量
  UpgradeSystem.ts              数据驱动祝福、前 10 次手选与后续自动成长
  Effects.ts                    粒子、残影和伤害数字池
  AudioManager.ts               BGM 循环、音效池、静音与 Web Audio 解锁
src/game/graphics/              程序化环境、角色动画与 WeaponRenderer 职业武器
src/game/ui/                    HUD、模态界面、摇杆和触控
public/assets/hero/             本地角色 PNG 与 Phaser 图集 JSON
public/assets/audio/            4 首循环 BGM（MP3）与 15 个程序化音效（WAV）
scripts/make-sfx.mjs            重新合成音效库（node scripts/make-sfx.mjs）
scripts/verify-audio.mjs        校验音频加载、播放与静音
docs/art/hero-prompts.md        生成提示词、素材来源与整理说明
```

actor 的位置代表脚底，碰撞只覆盖脚底。主角的视觉锚点为 `(0.5, 0.94)`，使用透明留白对齐脚掌；其他角色为 `(0.5, 1)`。地板静态图形烘焙为一张 RenderTexture，立体道具按深度单独绘制。敌方子弹最多 48、玩家投射物 64、粒子 100、伤害数字 12、敌人 15。

角色图集使用内置 `image_gen` 生成，原图保存为 `public/assets/hero/hero-atlas-v1.png`，头像为 `portrait.png`。`hero-atlas-v1.json` 将 16 个角色区域整理到统一的虚拟画布，不修改原 PNG 像素。需要重新整理时可手动运行 `python3 scripts/prepare-hero-atlas.py`（需要 Pillow）；正常安装、启动和构建不需要 Python 或图像生成服务。生成提示词和参考图保存在 `docs/art/`。

## 测试

```bash
npx playwright install chromium
npm test
```

浏览器集成测试覆盖双轴移动、斜向归一化、定向冲刺无敌、暂停冻结、三职业实际攻击与终结伤害、最近目标切换、完美格挡和普通减伤、职业祝福数值变化、第二波精英、死亡重开，以及手机多指操作、实际进入/退出全屏、画布无黑边、旋屏恢复和模拟不支持全屏的 Safari 回退。终结按钮还覆盖满能量但仍在技能锁定期的状态。战斗测试用指定站位消除随机障碍影响，伤害仍走真实攻击链路。

角色回归还验证透明素材实际加载、16 帧与脚掌对齐、四向行走切帧、攻击/冲刺/受伤姿态、残影使用新角色、隐藏的物理载体尺寸保持不变，以及菜单、头像、死亡重开和移动端操作没有旧角色残留。

成长回归完整执行十次手动卡片选择，验证第 11、12 次自动加成真实修改数值、弹幕提示、计时与长按攻击不中断，以及一次多杀跨过多个门槛时奖励不丢失。另覆盖暂停和死亡不发奖励、重开恢复手选、自动加成不缩短已有无敌时间，以及实际第 1～30、100 波生成的三类敌人生命值。新增回归验证每种增益只能选满 5 次、满级增益离开卡片候选、候选不足时只显示剩余数量、全部用满后不再发放祝福但门槛继续推进。

音频回归验证启动器加载完整音频库（4 首 BGM + 15 个音效）、职业 BGM 真正循环、战斗触发音效实例、声音按钮可静音与恢复，以及弹幕提示的不透明度落在可读但明显更暗的区间。

另检查紧凑横屏 568 × 320、667 × 375、844 × 390、932 × 430 的布局，以及多种地图种子的连通性。截图在 `artifacts/`。测试使用桌面 Chromium 和移动模拟，尚未在实体 Android / iOS 上验证。

首版为单主题、局内成长与无限递增波次，没有永久成长、存档或 Boss。
