# 1.1.0 战斗评估与数值边界

以下实测保留 1.1.0 首次评估时的血量与构筑快照。后续 Boss 加血补丁已将战役血量提高到 10000 / 25000 / 60000 / 150000 / 500000，快速挑战提高到 14600～17000；弹射补丁加入了每支箭对首目标一次有限返击，并修复穿透与多重箭组合。当前配置见 [README](../README.md)。下文旧 Boss 击杀时间及弹射单体说明不代表补丁后的结果；重跑工具会读取新配置。

运行 `npm run balance`，会启动独立临时 Vite 端口和 Chromium，生成 `artifacts/balance-110.json`。不连接生产游戏，不改变已有本地服务，不读取真实玩家纪录。

## 方法与可复现范围

- 54 条公式估算：3 职业 × 3 个明确属性快照 × 2 条现有核心路线 × 核心等级 0/1/3。
- 252 条引擎固定靶试验：单靶、五靶紧凑组、五靶直线，以及真实 Boss 的自动战斗；包含附弹旧策略的受控对照。
- 公式、快照、支持等级公开在 `BalanceEvaluation.ts`；实际试验调用现有 `CombatSystem`、弹丸轨迹、`Enemy.hit` / `Boss.hit`、寒霜、连锁、穿透、韧性与死亡路径。
- 固定 RNG 种子 `0x110F20`、60 Hz 逻辑步进；普通攻击测量 12 秒。暴击取确定的随机序列，公式取暴击期望，所以两者不会完全相等。
- `legacyMultishot: true` 仅把附弹恢复为旧版全伤，其余 1.1.0 规则保持一致，隔离这一项改动。它不是“整个旧版本”的性能对照。
- Boss 试验保留实际血量和阶段逻辑，固定距离，每 6 秒脚本完美格挡，能量满时立即释放终结技；关闭移动、来袭伤害和掩体。测得的是高命中条件下的自动战斗下限，**不是玩家击杀时间、单局时长或真人可玩性结论**。
- 早/中/晚是控制变量的属性快照，不表示玩家必然在某一波拥有这些升级。核心等级 3 的早期行用于隔离核心增幅，不声称是早期合法奖励进度。

最终报告运行条件：Linux x64、Intel Core i7-13620H、Node 22.16.0、Chromium 156.0.8078.4、1280×720、无头浏览器。252 项自动引擎试验墙钟 12,312 ms。该数字衡量工具执行时间，不能转换为手机 FPS。

## 发现与调整

### 终结技与防反

旧版 Boss 最大生命百分比同时乘以终结精炼与破防增伤。保留各职业基准比例与固定伤害，仅让固定伤害享受精炼和破防；百分比不再再次放大。单次终结对同一 Boss 的所有脉冲/箭矢共享 42% 最大生命总预算，独立 Boss 分开计算。

普通格挡仍是 80% 基础减伤和 0.35 倍攻击反击，没有百分比 Boss 伤害；完美格挡保留精准时机免伤、25 能量、6% 最大 Boss 生命反击、核心强化和削韧。完美格挡的百分比也不享受破防乘算。

按晚期固定快照（终结倍率 1.30）计算，对目前 125,000 HP 首领破防时：

| 职业 | 旧公式 | 1.1.0 公式 |
| --- | ---: | ---: |
| 近战 | 68,620.50 | 40,308.00 |
| 法师 | 80,740.53 | 47,709.28 |
| 弓箭 | 84,661.20 | 50,686.20 |

这张表是公式对照；极高倍率、破防期间所有脉冲实际命中的 100,000 HP 独立测试夹具另外验证伤害恰为 42,000，不会一键击杀。

### 群体吸血与充能

旧吸血每个目标独立全额回复，没有频率预算。晚期五靶理论可达 273.22 HP/秒，易使近战忽略走位。

现在按滚动 1 秒限额：`min(最大生命 × 12%, 单次吸血 × 5)`，同时不超过实际造成的伤害；晚期快照上限 40.8 HP/秒。实际单靶和群体试验均为 37.4 HP/秒，差异来自攻击间隔和滚动窗口，群体不会成倍回复。生命升级也会扩展这项预算。

普通命中充能按滚动 500 ms 限额 12 点，避免三弹×多目标瞬间满能。击杀和完美格挡的充能保留，终结技仍不能给自身充能。暂停不消耗窗口。

### 多重射击的覆盖取舍

旧多重弹在近距离全部命中同一目标时为无条件三倍伤害。现在主弹保持全伤，法师附弹 70%、弓箭附箭 55%；弹数、追踪、穿透、弹射、暴击与现有动画保留。升级卡明确说明附弹比例。

相同晚期属性、单核心 3 级、相同种子和固定靶阵型，实际普通攻击 DPS：

| 路线 | 单靶旧策略 → 新策略 | 五靶直线旧策略 → 新策略 |
| --- | ---: | ---: |
| 近战反击 | 956.67 → 956.67 | 1,898.33 → 1,898.33 |
| 近战旋风 | 1,267.17 → 1,267.17 | 2,693.67 → 2,693.67 |
| 法师冰冻 | 1,480.50 → 1,186.50 | 3,227.33 → 2,583.33 |
| 法师连锁 | 1,480.50 → 1,186.50 | 6,110.33 → 4,904.00 |
| 弓箭穿透 | 2,572.50 → 1,815.75 | 12,897.00 → 10,911.83 |
| 弓箭弹射 | 2,572.50 → 1,815.75 | 7,528.25 → 5,987.25 |

近战反击的普通攻击行**没有人为触发格挡强化**，不代表反击流的完整收益。冰冻控制收益也不能由 DPS 单独表达。穿透仍在列队时有优势，弹射适合分散目标，连锁对爆破外的目标增益明显；同一弹丸不会通过重复命中一个目标刷收益。

## 当前 Boss 自动试验

最终版读取配置：第一/第三/最终 Boss 为 4,000 / 18,000 / 125,000 HP。晚期核心 3 级固定靶试验中，近战 15.6 秒、法师 12.817 秒、弓箭 9.5 秒；均记录到最终 Boss 的阶段 2、3。此处所有攻击命中、没有移动或受击损失，且脚本每 6 秒完美格挡，**只是输出条件非常理想时的下限**。下一步平衡应结合真人的攻击空窗、躲避和格挡成功率，不应把这个下限直接作为设计目标。

## 后期成长与局限

- 六个核心及现有上限保持不变。卡片补充触发条件和弱项：持续近身、看准格挡、冰冻偏控制、连锁/弹射单体不追加、穿透需要拉成一线。
- 终结精炼仍提升固定伤害，并明确不放大 Boss 百分比。报告列出每级攻击精炼的 DPS 边际、终结精炼的 Boss 伤害边际；它们不再是同一维度的无条件乘算。
- 未借此扩大伤害或特效池：64 个玩家弹丸、96 个敌弹、8 个连锁队列、16 个环形特效的既有限制保留。
- 本工具不评估真人早期法师单体弱势是否足以由群伤、距离与控制补偿，也没有代替 Android/iOS 真机、50 波真人通关、主观趣味性或长期留存测试。
- 核心优劣依赖队形、走位与完美格挡成功率。后续优先补充几种不同熟练度的输入回放，而不是继续加统一伤害倍率。
