# 奶蛙：快乐回收站 — 1.1.0

可实际游玩的俯瞰 2.5D 动作 Roguelite。Phaser **4.0.0**、TypeScript、Vite 与 Arcade Physics，工程配置基于 [Phaser 官方 TypeScript + Vite 模板](https://github.com/phaserjs/template-vite-ts)。HTML/CSS HUD，无前端 UI 框架、后端、登录或在线素材依赖。

主角保留用户提供的黄色奶蛙角色、本地透明图集和头像。场景、敌人、武器与技能效果由代码绘制；四首 BGM 和 24 个音效均为本地文件。

## 战斗节奏与 Boss 交互

### 稳定自动索敌

优先级是：**射程内且无遮挡 → 无遮挡但射程外 → 其他候选**。同档候选保留合理范围内的当前目标，只有新候选明显更近时才切换；当前目标死亡、超出合理距离或持续被遮挡时重新评估。近战朝向、普通远程追踪与终结追踪继续共用有效目标；普通攻击和弹射受掩体限制，终结箭保留穿过掩体的能力。

武器三段动作与实际命中连击分开。每次真正命中累计连击，空挥不计数；连续 1.1 秒没有命中清零，暂停不消耗窗口。近战第三段保留 1.3 倍伤害。暴击、击杀、完美格挡和终结使用不同火花、数字、音效和短促反馈。

### 普通格挡与完美格挡

格挡持续 **650ms**，前 **180ms** 为完美窗口，基础冷却 **2400ms**。每次格挡动作最多触发一次反击。

- **普通格挡**：减伤 80%；反击为攻击力的 **0.35 倍**，不造成最大生命百分比伤害。波及真实攻击发出者及身边 **104 地面单位**内、无遮挡的其他敌人，定位为安全防御。
- **完美格挡**：免疫本次伤害，获得 **25 点终结能量**，清除近处弹幕并短暂震慑；基础反击为非 Boss 最大生命的 **35%**、Boss 最大生命的 **6%**，再加 `min(180, 攻击力 × 1.6)`。对 Boss 的 6% 部分不会被反击核心倍率放大，构筑只强化平伤。反击范围为 **160 地面单位**；近战反击核心可进一步扩大范围和提升收益。
- 两种反击均使用弹丸或近战伤害记录的真实攻击者；攻击者可以在远处，远处无关敌人不受伤。其他范围目标需要无遮挡。攻击者死亡后只处理附近目标。空格挡、冲刺无敌或同动作的后续受击不会重复触发。
- 防反不触发暴击、命中吸血、寒霜或普通命中充能，击杀仍计入回收数。近战反击核心可让格挡成功后短暂强化普通攻击，完美格挡额外削韧。

### Boss 韧性与破防

五位战役 Boss 分别有 **110～150 韧性**。完美格挡基础削韧 **34**；近战环斩、法师冻结触发和三职业终结也有独立削韧。普通格挡不会靠百分比伤害快速击杀 Boss。

韧性归零后，Boss 取消当前技能并停止攻击 **1.8 秒**，期间受到的固定伤害 **+35%**，Boss 最大生命百分比部分不再被放大；恢复后补满韧性，并有 **7 秒削韧保护**，防止连续无限破防。HUD 双条、角色脚下状态与「破防」提示共同展示状态。半血切换阶段时取消旧技能，并至少留出 850ms 再开始下一轮技能；最终 Boss 四分之一血进入第三阶段。

战斗停顿单次最多 45ms、请求有节流；屏幕震动最多 180ms、强度不超过 0.004，并限制触发频率。暂停设置可分别 **降低震动 / 减少动态效果**，后者取消命中停顿、关闭冲刺残影并降低粒子数量与运动幅度；设置保存到本地。

## 三职业构筑与成长

| 职业 | 普通攻击与核心方向 | 终结技 |
| --- | --- | --- |
| 近战 · 奶盖铲 | 近身横扫。**奶盖反击**：强化完美格挡冲击波、格挡后增伤与额外削韧。**快乐旋风**：连续命中扩大横扫，积累后释放额外环斩。 | 快乐大回旋：340 地面单位内三段回旋并清弹幕，总计 16 倍攻击力与额外百分比伤害。 |
| 法师 · 奶泡法杖 | 追踪爆破奶泡。**冰奶封存**：攻击叠寒霜，满层冻结；Boss 冻结为 185～395ms，独立入口上限 400ms，且有 5 秒独立冷却。**快乐连锁**：爆破向邻近未命中目标追加有限连锁。 | 奶泡天降：锁定落点，600ms 后在 360 地面单位内轰击，24 倍攻击力与额外百分比伤害。 |
| 弓箭 · 蛙友长弓 | 高速箭矢。**频道贯通**：额外穿透，后续目标伤害逐步增加。**蛙友弹射**：首目标返击一次，再转向邻近新目标，多重箭各自生效。 | 蛙友齐射：9 支追踪穿透箭，每支 4 倍攻击力与额外百分比伤害，可越过掩体。 |

战役第 **3 波结束**、快速挑战第 **2 波结束**获得入门核心；**非最终 Boss 胜利后**再选择一次核心，最终 Boss 直接进入奖励房，不再发放无用途的战斗加成。核心选择不消耗击杀获得的基础奖励。每职业有两种核心，每种最高 3 级，可组合；不能获得其他职业核心。

击杀门槛为 **4、9、14……**：前 **10 次基础加成**在波末暂停选择，战斗中只积累资格；多杀获得的多次奖励按顺序领取。此后基础奖励即时自动选择，不暂停战斗，已选择核心的协同升级在候选中具有更高权重；Boss 核心仍手动决定。

- 基础数值加成保留攻击、生命、攻速、冲刺、移动与暴击，以及原职业专属加成，每项通常最多 5 级，同时受属性实际上限限制。
- 获得核心后解锁对应协同加成，每项最高 8 级；累计 20 次基础奖励后解锁攻击、生命和终结威力精炼，每项最高 10 级，维持中后期有效成长。
- 卡片区分基础、稀有协同与核心，显示实际收益、当前等级和上限。暂停可查看已获得的核心与加成。
- 自动成长改为 **单条、2.8 秒、小型固定通知**：图标、名称、等级与关键数值；密集奖励排队并合并同类，最多保留 12 类待提示，不抢焦点、不暂停、没有横穿战场的大弹幕。
- 当前可用增益全部耗尽时只提示一次，之后静默推进奖励门槛。重开清除全部局内加成。

机制有明确边界：旋风连击窗口 1.6 秒，环斩不积累自己的触发计数，触发间隔至少 650ms；法师连锁每条最多 4 跳、同时最多 8 条，不递归生成新连锁；普通目标冻结也有冷却；弓箭穿透加伤最高 3 倍，弹射最多 3 次跨敌跳转。每支普通箭可对首个存活目标延迟 120ms 返击一次，不占跨敌跳转次数，随后仅寻找未命中的目标；同一支箭首目标最多受伤两次，其他目标最多一次，伤害逐跳衰减。多重箭各自持有命中与返击状态，返击也受原射程、寿命和掩体限制；前方没有可穿透目标时会及时转入弹射，已有穿透次数不会使弹射失效。

基础终结对 Boss 的额外最大生命伤害分别为近战累计 30%、法师 35%、弓箭每箭 4%，再叠加攻击力项与终结威力。终结命中不反向产生终结能量；破防时的增伤另行生效。原有连续武器动作、职业音效、冲刺残影、防反动画和 Boss 幽影碎裂死亡演出均保留。

## 五章战役与快速挑战

| 波次 | 章节 | 战斗决策 | Boss / 战役生命 |
| --- | --- | --- | --- |
| 1～10 | 蛙友广场 | 前期混合近战与远程，逐步引导走位、冲刺、格挡和终结。 | 复读机厂长 / 10000 |
| 11～20 | 弹幕频道 | 更多远程火力，宽窄三弹扇形交替，错开起手保留弹道间隙。 | 阴阳弹幕王 / 25000 |
| 21～30 | 缓存迷宫 | 加入有限的缓存掩体，重建寻路与攻击视线；掩体阻挡普通攻击和弹幕。 | 缓存堵塞者 / 60000 |
| 31～40 | 热搜风暴 | 地面周期危险提前 **1450ms** 标记落点，鼓励移动；Boss 波关闭环境危险。 | 热搜风暴 / 150000 |
| 41～50 | 红温总控 | 精英、远程与近战混编，普通波增加第二处错开的环境危险；最终 Boss 有三阶段。 | 红温总控 / **500000** |

章节更换地板色调、地面图案、标牌与提示。第三章的新增掩体避开玩家站位，出生点重新检查实际脚底碰撞，跨章移除掩体时同步更新导航与弹丸遮挡。中心通道保持畅通，不生成封死全图的墙。精英半血出现状态圈、短暂喘息并缩短后续攻击间隔。

普通敌人仍为近战、远程与精英三类，单波最多 15 个；出生距离避开玩家近处；安全点不足时减少本波数量，不回退到近身或重复出生点。普通生命、伤害从当波基础重新计算，不把上一波数值反复连乘。第 36 波起增加额外压力：令 `n = 波次 − 1`、`p = max(0, 波次 − 35)^2`，生命倍率为 `1 + 0.16n + 0.025n^1.5 + 0.004p`，伤害倍率为 `1 + 0.1n + 0.00025p`。速度增长最多计算 12 波；章节难度同时来自组合、节奏、掩体与环境。

**快速挑战独立为 10 波**，第 10 波随机使用五种 Boss 之一，其生命调整为 `14000 + Boss 章节 × 600`、伤害为 25、韧性为 110，保留所选 Boss 的技能特点。普通波在短局中调整敌人组合，波间恢复 15 生命（战役为 10）；更早获得入门核心。两模式都在最终 Boss 死亡演出后直接进入可移动的「快乐小卖部」，走近或点击领取「蛙友快乐认证」，不会继续生成第 11 / 51 波。

## 本地记录与设置

`localStorage` 按 **模式 × 职业**分别保存最高已清波次、最快胜利用时、最高连击、最高击杀、场次与胜场。死亡时记录已完成的上一波：例如死在第 5 波，最高已清为 4。通关进入奖励房时记录一次，重复领奖不重复计数；最快时间只比较胜局，暂停、升级和奖励房探索不计入战斗用时。

菜单展开面板、选中职业下方与结算显示记录。存档逐字段校验，兼容缺少版本的旧部分数据；损坏内容或浏览器拒绝存储不会阻止游戏，拒绝写入时保留会话内记录。键为 `naiwa.records.v1` 与 `naiwa.preferences.v1`。

记录不提供永久属性加成。目前没有局内断点恢复；刷新会开始新局，不自动恢复未结束的战斗。

玩家物理载体与角色视觉分离：脚底碰撞为 24 × 14，偏移 `(12,49)`；透明角色按 `(0.5,0.94)` 锚点对齐脚掌。武器、身体和技能动画不改变脚底碰撞。地板烘焙为 RenderTexture，立体道具单独按 Y 排序。池上限为敌方子弹 96、玩家投射物 64、粒子 100、伤害数字 12、技能图形 24、Boss 幽影 2、环境危险 2。死亡、重开与场景关闭清理引用和效果；HUD 数值缓存，触控冷却按 1% 量化，避免每帧重建 DOM。

角色图集由内置图像生成工具基于用户参考图生成：`hero-atlas-v1.png` 保留原图，`hero-atlas-v1.json` 将 16 帧整理至统一虚拟画布。来源和提示词见 `docs/art/hero-prompts.md`；需要重整图集时运行 `python3 scripts/prepare-hero-atlas.py`（仅该工具需要 Pillow）。正常安装和运行不需要 Python 或在线生成服务。

四首离线生成、无人声 MP3 分别用于菜单及三职业，44.1 kHz 立体声。`scripts/make-sfx.mjs` 合成 24 个 WAV，包含通用反馈与三职业各自的攻击、冲刺、格挡。`BootScene` 加载全部 28 个音频；`AudioManager` 使用每效果 3 声部与触发节流，首次用户手势后解锁播放，音符按钮统一静音。已有本地素材保留，不依赖第三方在线游戏资源。


## 1.1.0：节奏与构筑打磨

- 快速挑战每两波进入下一章，与五章地板、掩体、敌人组合、环境危险及提示同步；完整战役仍为每十波一章。布局切换后先重建寻路与攻击遮挡，再选择安全出生点。
- 普通波间隔 900ms，章间 1400ms，Boss 登场 2200ms，Boss 战后及最终庆祝 1800ms。前期手动奖励领取完毕后才开始等待；暂停冻结倒计时。完整战役非最终过场合计 54.2 秒（旧版 137.2 秒），这是配置总和，不是真人通关时长。
- 最终 Boss 不再提供核心或基础升级，直接进入保留奖章的快乐小卖部。战役有入门加四次 Boss 核心，快速挑战保留入门核心；结算与纪录幂等。
- Boss 血量再次加强为 10000 / 25000 / 60000 / 150000 / 500000；快速挑战随机 Boss 为 14600～17000。后半阶段有不同技能序列、明确出口和重新预警，最终第三阶段保留可读的高潮。
- 战役与快局通过 `DifficultySystem.getBossMaxHealth` 统一读取血量配置；补充实际生成、重生、阶段切换与死亡回归。修复手机旋转时 Phaser 父容器已更新但画布仍停在旧尺寸的竞态，销毁时清理新增监听。
- 终结升级与破防继续放大固定伤害，Boss 百分比伤害不再重复乘算；一次终结对同一 Boss 最多造成其最大生命 42% 的总伤害。附加奶泡为主弹的 70%，附箭为主箭的 55%，首发保持全伤。吸血与普通命中充能使用暂停感知的滚动预算，详细值和可复查的靶场前后对照见交付记录。
- 六种核心保留各自的优势：反击需要准确防御，旋风需要连续近身命中，寒霜需要叠层与独立冻结冷却，连锁需要目标聚集，穿透依赖阵型，弹射提供有限单体返击与散敌接力。单靶伤害不会代表全部构筑价值。
- 连击保留有效命中规则，10 / 25 / 50 / 100 有小型里程碑反馈，中断给简短提示；不额外发放伤害或分数，避免职业命中频率偏置。
- 结算可展开本局构筑、真实 HP 伤害、防御减免、格挡/终结/破防与各 Boss 的自动计时记录。活跃局内用时含波间、不含暂停、选择、奖励房和命中停顿；另有仅敌人在场时累计的交战用时。评分透明：进度 60、防守 20、完美格挡 10、节奏 10；S≥90、A≥75、B≥60，否则 C，完整计算说明随结算展示。各模式/职业新增可选最高评分，旧存档兼容。
- 568×320 起的暂停、死亡、通关面板固定主要操作，详细内容独立滚动；Boss 血量与韧性分条显示，低血/终结就绪更清楚。触控捕获失败时仍可通过窗口事件正常松手，旋转/全屏/失焦清理输入。

```bash
npm run balance  # 独立 Vite + 固定种子理论与真实 CombatSystem 靶场，输出 artifacts/balance-110.json
```

## 测试与已知边界

浏览器测试覆盖原有移动、职业攻击、连击、音频、动画、升级、地图与奖励房，并加入普通/完美格挡差异、韧性与破防保护、Boss 阶段转换、遮挡索敌和目标稳定性、六种构筑及上限、核心奖励资格、五章与两种波次上限、分模式记录、异常存储、舒适度和两套触控布局。多点触控使用 Chromium CDP 真实触摸事件；小屏回归检查 568 × 320、667 × 375、844 × 390 等横屏的按钮间隔、界面溢出、旋转、暂停与全屏。

Playwright 截图输出到 `artifacts/`，包括菜单、暂停、核心卡片、战斗、Boss 与奖励房。`scripts/verify-audio.mjs` 可额外检查本地音频波形和播放；生产分享检查见 `scripts/verify-public.mjs`。1.0.0 历史交付执行过 111 项测试（5.0 分钟），详见 [1.0.0 交付记录](docs/optimization-1.0.0.md)。1.1.0 的实际验证与测量条件见 [1.1.0 打磨记录](docs/optimization-1.1.0.md)。

当前验证环境为桌面 Chromium 与移动模拟，**尚未在实体 Android / iOS 上验收**。50 波完整战役的长期数值仍需实际玩家游玩反馈；尚未实现局内安全断点恢复、离线缓存或后端同步。全屏及横屏锁定取决于浏览器能力。
